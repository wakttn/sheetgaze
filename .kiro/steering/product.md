# Product Overview

`sheetgaze` は、xlsx / csv ファイルをターミナル上で閲覧し、数式の計算結果を確認するための TUI ツールである。オフィススイートを起動せず、SSH 経由のリモート環境でも素早く表計算の内容を把握できることを目指す。

## Core Capabilities

- xlsx / csv のローカルファイルを読み込み、表として表示する
- xlsx の数式を Excel 互換エンジンで再計算し、キャッシュ値とあわせて表示する
- 改行・結合セル・文字色・太字を含むセルを、端末表示の制約内で再現する
- Excel に保存されたオートフィルタを読み込み、表示の絞り込みに利用する
- Excel で固定された行・列をスクロール中も表示する
- セル値と数式を対象とした検索、一致間の移動、強調表示を提供する
- csv の文字コードを自動判定し、必要に応じて明示指定できる
- 大容量ファイルでは行単位の遅延ロードと上限付きキャッシュでメモリを抑える
- Excel の列幅・行高設定を優先し、未設定の行・列は内容に応じて自動調整する（上限値を設定可能）
- キーボード中心のナビゲーション、セル詳細表示、単一セルおよび範囲コピーを提供する

## Target Use Cases

- リモートサーバー上の xlsx / csv を、GUI やオフィススイートなしで確認する
- 数式の計算結果やエラーを、セル単位で素早く確認する
- 長い文字列や改行を含むセルを、表示崩れなく調査・コピーする
- Excel で設定済みのフィルタ条件をそのまま使って、目的の行を絞り込む
- 数万行の csv / xlsx でも、行キャッシュを制限しながら閲覧する
- ターミナル上で Vim に近い操作感のまま表を巡回する

## Value Proposition

- 単一の Rust バイナリで動作し、外部オフィススイートや非 Rust ランタイムを必要としない
- 表示専用に割り切ることで、巨大な表でも起動と操作を軽量に保つ
- 数式計算をバックグラウンドで行い、計算中も閲覧操作を妨げない
- ターミナル幅・高さの制約を前提に、はみ出し表示・結合セル・改行を一貫した規則で扱う
