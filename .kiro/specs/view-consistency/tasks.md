# Implementation Plan

## 1. Foundation: 共有ビューステート

- [x] 1.1 固定ペインの有効状態とレイアウト設定を一元化する
  - 無効化された固定ペインが 0 行・0 列として扱われるようにする
  - 表示領域に収まらない固定行・列を制限し、制限フラグを保持する
  - シートが読み込み時のレイアウト上限を保持し、後続の更新で再利用できるようにする
  - 固定ペイン無効時に行・列が固定されないことをテストで確認できる
  - _Requirements: 3.1, 3.2, 3.3, 3.5_

- [x] 1.2 フィルタ列マスクの値モデルと合成規則を追加する
  - フィルタ列ごとの一致マスクを構築・保持できるようにする
  - 値リスト、カスタム条件、Top10、未対応条件のマスクを既存規則どおり評価する
  - 全体・列単位の有効状態から最終的な可視行を合成できるようにする
  - 固定行を可視のまま維持する合成結果をテストで確認できる
  - _Requirements: 4.1, 4.2, 4.5, 6.1_

- [x] 1.3 セル計測とレイアウト変更の共通型を追加する
  - 表示幅、折り返し行、はみ出し、切り詰め、結合スパンを一つの計測結果として扱う
  - 数式結果などで変更された行・列を表すレイアウト変更情報を追加する
  - グリッドと詳細が同じ計測結果から切り詰めを判定できるようにする
  - 代表的なセルで計測結果と切り詰め判定が一致することをテストで確認できる
  - _Requirements: 5.1, 5.5, 5.6_

## 2. Viewport とフォーカス表示

- [x] 2.1 フォーカスに追従する縦横ビューポートを実装する
  - 右・左・上下の移動で表示開始位置を最小限に調整する
  - 固定行・固定列とフィルタ可視行を考慮する
  - 結合セルを一つの論理セルとして扱い、表示幅を超える場合は左端を優先する
  - 端末サイズ変更後もフォーカスが表示領域内に残ることをテストで確認できる
  - _Requirements: 1.1, 1.2, 1.3, 1.4, 1.5, 1.6, 6.2_

- [x] 2.2 通常モードのフォーカスカーソルを描画計画に追加する
  - 選択範囲の有無にかかわらずフォーカスセルをカーソルとして識別できるようにする
  - 選択範囲の強調とカーソルを別の状態として描画できるようにする
  - 結合範囲ではアンカーをフォーカス位置として扱う
  - 通常モードと選択モードでカーソル状態が正しく計画されることをテストで確認できる
  - _Requirements: 2.1, 2.2, 2.3_

## 3. フィルタ可視性と検索

- [x] 3.1 xlsx / csv の読み込み時にフィルタマスクを構築する
  - eager と遅延シートの両方で列マスクを構築する
  - 初期可視行をマスク合成から生成し、固定行を可視に保つ
  - 遅延 xlsx でも結合セルの幅要求を eager と同じように記録する
  - 保存済みフィルタを持つ fixture が eager / lazy で同じ初期可視性になることをテストで確認できる
  - _Requirements: 4.1, 5.3_

- [x] 3.2 シートの可視性再構築をマスク合成へ切り替える
  - フィルタ切替時に全行を再走査せず、保持済みマスクを合成する
  - 遅延シートでも eager に変換せず可視行を更新する
  - 数式再計算後はマスクを dirty にし、必要なシートだけ再構築する
  - 再構築失敗時は以前の可視性を保持し、状態表示できるようにする
  - 遅延シートでフィルタを無効化・再有効化した際に可視行が戻ることをテストで確認できる
  - _Requirements: 4.2, 4.3, 4.4, 4.5, 6.1_

- [x] 3.3 検索結果を可視一致へ同期する
  - 検索確定時に最初の可視一致へフォーカスする
  - 非表示の一致件数を直ちに更新する
  - 可視一致がない場合はフォーカスを変更せず状態表示する
  - 最初の一致が非表示のケースと全一致が非表示のケースをテストで確認できる
  - _Requirements: 4.6, 4.7_

## 4. テキストレイアウトと数式結果

- [x] 4.1 明示改行・wrap_text・結合セルのレイアウトを統一する
  - 明示改行と折り返し後の行数から行高を決める
  - 結合セルの幅・行高要求を列・行へ分散する
  - eager と遅延シートで同じレイアウト結果になるようにする
  - はみ出しと切り詰めの既存規則を維持する
  - wrap_text セルの行高が折り返し行数になり、詳細の切り詰めと一致することをテストで確認できる
  - _Requirements: 5.1, 5.2, 5.3, 5.6_

- [x] 4.2 数式再計算結果を grow-only でレイアウトへ反映する
  - 再計算後の表示値で列幅・行高を必要な分だけ拡大する
  - 既存の幅・行高を縮小しない
  - 数式結果の適用サマリでレイアウト変更とフィルタマスクの dirty 化を通知する
  - 再計算後に長い表示値が切り詰められないことをテストで確認できる
  - _Requirements: 5.4_

- [x] 4.3 詳細表示の切り詰め判定をグリッドと共有する
  - 詳細表示がグリッドと同じ計測結果から切り詰めを判定する
  - 静的で空の切り詰め集合に依存しないようにする
  - 切り詰めの有無がグリッドと詳細で一致することをテストで確認できる
  - _Requirements: 5.5_

## 5. アプリケーション統合と UI

- [x] 5.1 AppState にビューポート・可視性・数式結果を統合する
  - 移動、リサイズ、シート切り替え、検索移動、フィルタ変更の各経路でビューポートを更新する

  - 詳細表示の切り詰めと固定領域の状態表示を反映する
  - キーボード操作だけで移動・検索・フィルタ・詳細が一貫して動くことをテストで確認できる
  - _Requirements: 1.1, 1.2, 1.3, 1.4, 1.5, 1.6, 2.1, 2.2, 2.3, 3.1, 3.2, 3.3, 3.4, 4.2, 4.3, 4.4, 4.5, 4.6, 4.7, 5.4, 5.5_

- [x] 5.2 固定領域制限とフィルタ・検索状態をステータスへ表示する
  - 固定領域が制限された場合に状態表示へ反映する
  - フィルタ可視行数と検索の可視・非表示件数を既存のステータス表示で確認できる
  - 無効化された固定ペインで固定ラベルが表示されないことをテストで確認できる
