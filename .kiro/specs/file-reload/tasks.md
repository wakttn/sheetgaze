# Implementation Plan

## 1. Foundation: 監視設定と変更判定

- [x] 1.1 監視設定とファイルスタンプを追加する
  - `--watch poll|native|auto|off` と `--watch-interval-ms` を既定値付きで解釈し、範囲外を使用法エラーにする
  - ファイルスタンプに存在有無を加え、削除・再作成をサイズと mtime と区別できるようにする
  - 監視方式・ポーリング間隔・デバウンス・再試行・保険確認の既定値が一箇所から取得できる
  - 既定値、境界値、不正値、存在しないファイルのスタンプ比較がテストで確認できる
  - _Requirements: 1.4, 1.10, 6.1, 6.2, 6.8, 6.9, 7.7_

- [x] 1.2 デバウンス・安定確認・再試行の状態機械を実装する
  - 自動通知は安定待ちの期限まで待ち、期限時のスタンプが検出時と同じ場合だけ読み込みを許可する
  - 変更が続く間は期限を延長し、読み込み中の追加通知は完了後の再評価に回す
  - 手動リロードは安定待ちをバイパスし、読み込み中の重複要求は即時実行しない
  - 読み込み失敗時に 1 秒間隔の再試行を予定し、初回・3 回目・以降 3 回ごとの通知要否を返す
  - 通常変更、連続変更、期限到達、手動、失敗、復旧、読み込み中変更が仮想時刻の単体テストで確認できる
  - _Requirements: 1.6, 2.1, 2.4, 2.7, 3.3, 3.6, 3.8, 4.2, 4.3_

## 2. I/O アダプタ: ローダーと監視

- [x] 2.1 起動時と再読み込みで共有するワークブックローダーを追加する
  - 拡張子から形式を判定し、xlsx / xlsm / csv を同じ設定で読み込む
  - lazy の always / never 上書き、文字コード、レイアウト上限、フィルタ初期状態を引き継ぐ
  - 読み込み失敗は既存のエラー型で返し、元ファイルを変更しない
  - 起動時と再読み込みで同じ形式・同じフィルタ初期状態になることをテストで確認できる
  - _Requirements: 1.1, 1.2, 2.8, 3.1, 7.1, 7.6_

- [x] 2.2 ポーリングとネイティブ監視のセッションを追加する
  - 既定は 1 秒間隔・内容比較なしのポーリングとし、監視対象ファイルと親ディレクトリを非再帰で監視する
  - ネイティブ監視の登録失敗と実行時エラーをポーリングへフォールバックする
  - auto は Linux のマウント情報、Windows の保守的判定、macOS のネイティブ監視を選ぶ
  - 監視対象外の兄弟ファイルの通知だけでは読み込みを開始しない
  - 変更通知、置換保存、監視登録失敗、auto 判定がテストで確認できる
  - _Requirements: 1.1, 1.3, 1.5, 1.7, 1.8, 1.9, 1.10, 6.3, 6.4, 6.5, 6.6, 6.7, 6.10_

## 3. ワーカーと数式世代

- [x] 3.1 数式再計算の世代管理とキャンセルを追加する
  - ワークブックごとに世代を進め、現在の世代と一致する結果だけを適用する
  - 再読み込み時に旧ジョブをキャンセルし、旧世代の成功・失敗メッセージを破棄する
  - 再計算ポリシーによるスキップ理由を状態表示へ渡す
  - 遅い再計算中の再読み込みで古い値が混入しないことをテストで確認できる
  - _Requirements: 2.5, 2.6, 5.10_

- [x] 3.2 監視・待機・読み込み・再試行を行うリロードワーカーを追加する
  - 監視通知、手動要求、タイマーを単一スレッドで直列処理する
  - 成功時に新しいワークブックを UI へ渡し、失敗時は旧表示を保持して再試行する
  - 読み込み中に変更された場合は、完了後に最新スタンプで 1 回だけ再評価する
  - 終了要求で監視を停止し、UI スレッドは読み込み完了を待たない
  - 自動変更、手動、保存途中、連続変更、3 回失敗、復旧、終了が統合テストで確認できる
  - _Requirements: 1.9, 2.1, 2.2, 2.3, 2.4, 3.1, 3.2, 3.3, 3.4, 3.5, 3.6, 3.7, 3.8, 4.1, 4.2, 4.3, 4.4, 4.5, 4.6, 7.1, 7.4_

## 4. 表示状態と UI の統合

- [x] 4.1 再読み込み後の表示状態を引き継ぐ
  - シート名、フォーカス、選択、開いている画面を新しいワークブックへ引き継ぐ
  - 範囲外のフォーカスと選択をクランプし、非表示行では近傍の可視行へ移動する
  - フィルタの有効状態を定義の同一性に基づいて引き継ぎ、非互換時は初期状態へ戻して通知する
  - 検索結果を破棄し、成功時に以前のエラーを消して再読み込み結果を表示する
  - シート削除、列数減少、フィルタ変更、非表示行、詳細表示中の差し替えがテストで確認できる
  - _Requirements: 2.3, 3.1, 3.4, 4.4, 4.5, 5.1, 5.2, 5.3, 5.4, 5.5, 5.6, 5.7, 5.8, 5.9, 5.10, 7.3, 7.8_

- [x] 4.2 手動リロードのキー・ヘルプ・状態表示を追加する
  - 通常モードの r キーを手動リロード要求へ割り当てる
  - 監視方式とフォールバック状態をステータス行に表示する
  - ヘルプに r の説明を追加し、既存キーバインドを変更しない
  - r、watch ラベル、ヘルプ、既存キー操作が TUI テストで確認できる
  - _Requirements: 2.3, 3.2, 4.7, 4.8, 5.10_

- [x] 4.3 イベントループと起動処理を統合する
  - 起動時の読み込みを共有ローダーへ置き換え、監視ワーカーと数式ランナーを起動する
  - リロードメッセージ適用後に数式再計算を再起動し、旧世代を破棄する
  - 監視無効時は既存動作を維持し、再読み込み中も描画・キー入力・終了を継続する
  - 自動リロード、手動リロード、監視 off、再読み込み中の終了が統合テストで確認できる
  - _Requirements: 1.9, 2.2, 2.6, 3.2, 6.2, 7.2, 7.4, 7.5_
