# Implementation Plan

- [x] 1. 基盤となる表示契約を追加する
- [x] 1.1 `LayoutSnapshot` と `ColumnWidths` に xlsx 幅優先の行高契約を追加する
  - `wrap_row_heights`、`display_row_height`、`grow_wrap_height` を追加する
  - `ColumnWidths::from_sheet` を xlsx 幅優先、`fit` を非優先として生成する
  - fit-width 時は追加行高を参照しない
  - 既存の読み込み結果では追加行高が空のままである
  - _Requirements: 1.1, 1.2, 1.6, 3.3, 3.4, 4.1, 4.4, 6.4_

- [x] 1.2 はみ出し幅と折り返し行数の共通計算を追加する
  - 右隣の空セル、値、結合、左右罫線、使用範囲終端で停止する既存規則を純粋関数へ移す
  - ガターを含むはみ出し可能幅と `spilled` を返す
  - 全文がはみ出し幅に収まらない場合の折り返し行数を `--max-row-lines` でクランプする
  - `wrap_text` と明示改行は対象外として `None` を返す
  - _Requirements: 1.3, 1.4, 1.5, 3.5, 6.1, 6.2_

- [x] 2. 読み込み時に折り返し行高を確定する
- [x] 2.1 eager 読み込みで対象セルの追加行高を計算する
  - 明示列幅・単一行・非 `wrap_text`・自列幅超過のセルだけを候補にする
  - レイアウト確定後の列幅と使用範囲ではみ出し可能幅を求め、行ごとの最大行数を `wrap_row_heights` に設定する
  - content レイアウトと csv では候補を作らず、列幅・基本行高・既存の wrap 行高を変更しない
  - fixture を eager で読み、対象行に追加行高が設定される
  - _Requirements: 1.1, 2.1, 2.2, 3.1, 3.2, 6.3_

- [x] 2.2 lazy 読み込みで候補セルと停止位置から追加行高を計算する
  - 行確定時に候補セルと右方向の停止位置だけを保持する
  - 最終使用範囲と列幅の確定後に折り返し行数を求める
  - 候補以外のセル文字列を読み込み後まで保持せず、content レイアウトでは候補を作らない
  - 同じ fixture を eager / lazy で読み、`wrap_row_heights` が一致する
  - _Requirements: 1.1, 2.2, 3.1, 3.2, 5.3, 6.3_

- [x] 2.3 明示列幅を含む結合範囲の追加行高を計算する
  - 結合範囲が明示列幅の列を含み、非 `wrap_text`・単一行で結合幅を超える場合だけ対象にする
  - 必要な折り返し行数を結合範囲の行へ既存と同じ均等配分で加算する
  - 明示行高が下限として残る
  - 結合セルの長文が折り返し行数分の高さを持つ
  - _Requirements: 2.3, 3.1, 3.2, 3.3, 3.4, 3.5_

- [x] 3. 描画とナビゲーションを実効行高へ接続する
- [x] 3.1 非結合セルの折り返し表示をグリッドと詳細に実装する
  - 全文がはみ出し幅に収まる場合は従来の1行はみ出しを維持する
  - 収まらない場合だけはみ出し幅で折り返す
  - `RenderCell.width` ははみ出し幅、`slot_width` は自列幅のままにする
  - グリッドと `measure_cell` の折り返し・`truncated` が一致する
  - _Requirements: 2.1, 2.2, 2.4, 2.5, 2.6, 3.5_

- [x] 3.2 結合セルの折り返し表示を実装する
  - 結合範囲が明示列幅を含み、結合幅を超える場合に折り返す
  - 結合範囲の実効行高合計で表示行をスライスする
  - 結合セルの長文が折り返し表示され、隣接セルを上書きしない
  - _Requirements: 2.3, 2.4, 2.6, 3.5_

- [x] 3.3 `LayoutEngine` の計画・freeze・詳細で実効行高を使う
  - `plan` / `effective_freeze` / `measure_cell` の行高参照を `display_row_height` に置き換える
  - 結合範囲の高さ計算も実効行高を使う
  - xlsx 幅優先時だけ追加行高が反映される
  - 明示行高より折り返し行数が多い行が正しい高さで計画される
  - _Requirements: 3.1, 3.2, 3.3, 3.4, 3.6, 4.4_

- [x] 3.4 `ViewportPlanner` の縦スクロールを実効行高へ対応させる
  - 可視行の高さ計算に `display_row_height` を使う
  - fit-width 時は追加行高を無視する
  - 折り返しで高い行へ移動してもフォーカス行が画面内に残る
  - _Requirements: 3.6, 4.1_

- [x] 4. 編集・数式・構造変更後の行高を更新する
- [x] 4.1 編集後の行・結合セルの折り返し行高を再評価する
  - 影響行の固定列セルを再走査し、grow-only で追加行高を更新する
  - 結合セルは結合範囲単位で再計算する
  - 隣接セルを埋めても左側の長文が折り返される
  - `truncated` がグリッドと詳細で一致する
  - _Requirements: 5.1, 5.5, 5.6_

- [x] 4.2 数式再計算結果の反映後に折り返し行高を再評価する
  - 表示文字列が長くなった行で `refresh_wrap_row` を呼ぶ
  - 数式の計算結果が長文になった場合に行高が広がる
  - _Requirements: 5.2, 5.6_

- [x] 4.3 再読込・行構造編集・列構造編集の追加行高を整合させる
  - 再読込では新しいセル内容と列幅から再計算する
  - 行挿入・削除では追加行高をシフトする
  - 列挿入・削除では古い幅に基づく追加行高を再計算する
  - 構造編集後も行高と列幅が対応する
  - _Requirements: 5.3, 5.4, 5.5_

- [x] 5. fixture とテストを追加する
- [x] 5.1 (P) 明示列幅の折り返し fixture を追加する
  - 完全にはみ出せる長文、隣接値で塞がれた長文、罫線で止まる長文を含める
  - 明示行高、結合範囲、`--max-row-lines` 到達ケースを含める
  - fixture が決定的に再生成できる
  - _Boundary: Test Fixtures_
  - _Requirements: 6.2_

- [x] 5.2 (P) はみ出し幅と折り返し行高の単体テストを追加する
  - 値・結合・罫線・使用範囲終端・ガターの停止条件を検証する
  - 収まる場合は折り返さず、収まらない場合だけ行数を返すことを検証する
  - fit-width 時に追加行高を無視することを検証する
  - _Boundary: Domain Tests_
  - _Requirements: 6.1, 6.2_

- [x] 5.3 グリッド・詳細・print・編集の統合テストを追加する
  - plan と `measure_cell` の折り返し・切り詰めが一致する
  - eager / lazy で同じ追加行高になる
  - print スナップショットに折り返し行が表示される
  - 編集・数式再計算後の行高更新が反映される
  - _Depends: 5.1_
  - _Boundary: Integration Tests_
  - _Requirements: 2.6, 3.6, 5.1, 5.2, 5.6, 6.5_

- [x] 5.4 (P) 既存モードと切り詰めの非回帰テストを追加・更新する
  - 明示幅を持たない `overflow.xlsx` の既存期待値を維持する
  - fit-width、content レイアウト、csv、`wrap_text` の既存テストが通る
  - `--max-row-lines` 到達時は `…` と `truncated` が一致する
  - _Boundary: Regression Tests_
  - _Requirements: 4.2, 4.3, 4.6, 6.3, 6.4_

- [x] 6. ドキュメントと全体検証
